LUMEN FARM - VERSIONES Y CAMBIOS
================================

COMO SE NUMERAN LAS VERSIONES
-----------------------------
  0 . 1 . 0 - alpha
  |   |   |     |
  |   |   |     +-- etapa: alpha (falta probarlo en el juego), beta (funciona en el juego y lo
  |   |   |         prueban otros), nada a partir de la 1.0 (estable)
  |   |   +-- ARREGLO: fallos, textos, retoques visuales, datos (equipos, premios, medidas)
  |   +------ NOVEDAD: algo nuevo que se nota al usarlo (un modo, una funcion, una pagina)
  +---------- GRANDE: 1.0.0 = el lanzamiento. Despues, solo un cambio enorme (rediseno total o
              algo que obliga a configurar de nuevo) sube a 2.0.0

Reglas:
- Una version por actualizacion (cada PR que se aprueba), no por cada cambio pequeno.
- Se sube segun lo MAS grande que traiga: si trae una novedad y tres arreglos, es novedad.
- Al subir un numero, los de su derecha vuelven a 0 (0.3.2 + novedad = 0.4.0).
- Ejemplos: un modo nuevo o el plan del dia -> novedad. Casillas que no se veian, un texto
  cortado, el tiempo medido de un equipo -> arreglo.

Etapas previstas:
  0.x-alpha  ahora: todo esta hecho pero casi nada se ha probado con el juego
  0.x-beta   cuando funcione en el juego y lo prueben otras personas
  1.0.0      el lanzamiento, cuando la beta vaya bien un tiempo sin fallos graves

(Las versiones 2.x y 3.x eran de TrefotFarm, el nombre anterior. Lumen Farm empieza de cero.)
