TREFOT // FARM  -  PRIMEROS PASOS
==============================================================

Bot para The Seven Deadly Sins: Grand Cross (cliente de PC). Esta copia es para probarlo.
Ojo: usar bots va contra las reglas de Netmarble y puede costar un baneo. Pruebalo bajo tu riesgo.


1. LO QUE NECESITAS
-------------------
- Windows 10 u 11.
- El juego para PC, en ingles (version Global). Con el juego en otro idioma algunos botones
  pueden no reconocerse.
- Python 3.12: descargalo de https://www.python.org/downloads/ (version 3.12.x).
  Al instalar, MARCA "Add python.exe to PATH" y deja marcado "py launcher".


2. INSTALAR (una sola vez)
--------------------------
OPCION A - con Git (recomendada: recibes las actualizaciones solo)
  1. Pide que te inviten al repositorio de GitHub y acepta la invitacion (necesitas cuenta).
  2. Instala Git para Windows: https://git-scm.com/download/win (opciones por defecto).
  3. En la carpeta Documentos: clic derecho -> "Open Git Bash here" y escribe:
         git clone https://github.com/Trefot/TrefotFarm.git
     La primera vez se abre el navegador para iniciar sesion en GitHub.
  4. Entra a la carpeta TrefotFarm y haz doble clic en "Instalar.bat". Tarda unos minutos.

OPCION B - con el .zip (no recibe actualizaciones)
  1. Descomprime el .zip en un sitio fijo, por ejemplo Documentos\TrefotFarm.
  2. Doble clic en "Instalar.bat". Tarda unos minutos.


3. ABRIR
--------
1. Abre el juego y llega a la Tavern.
2. Doble clic en "TrefotFarm.bat" y ACEPTA el aviso de administrador de Windows
   (el juego corre como administrador y sin ese permiso el bot no puede hacerle clic).
3. Si no abre, usa "TrefotFarm_con_consola.bat" para ver el error.


4. ANTES DE FARMEAR
-------------------
- Pagina "Personajes": haz clic en los personajes que tienes (a color = lo tienes).
- Por ahora el bot sabe jugar un solo contenido: Skollandhati & Hati (perros), Floor 4, con
  este equipo de izquierda a derecha: Odin, Gawain, Freyja (Strength) y Thonar (Speed).
  Si no tienes ese equipo puedes ver la interfaz, pero el bot no podra farmear.
- Pagina "Equipos": muestra los equipos recomendados y que te falta.


5. PROBARLO
-----------
1. Pagina "Inicio": revisa que los 4 puntos de "Antes de empezar" esten en verde
   (cada uno tiene un boton para arreglarlo).
2. Victorias: elige 1 para la primera prueba.
3. Pulsa "Empezar" y NO muevas el raton mientras juega.
   - F9 = pausa, F10 = detener.
   - Para frenarlo de golpe: lleva el raton a una esquina de la pantalla.


6. ACTUALIZACIONES
------------------
- Con Git (opcion A): al abrir y al pulsar Empezar, el programa busca version nueva. Si la hay,
  es obligatoria: pulsa "Actualizar ahora" y se reinicia solo.
- Con el .zip (opcion B): en Inicio saldra "No hay repositorio remoto configurado". Es normal;
  para una version nueva, pide otro .zip.


7. SI ALGO FALLA
----------------
Manda estos archivos de la carpeta "logs":
- sesion_<fecha>.log  (lo que hizo el bot en cada sesion)
- errores.log         (si hubo errores inesperados)
y cuenta que viste en el juego cuando fallo.
